# Contributing

Thanks for helping out.

## Getting started

* Requires Java 21 and Maven.
* Build and test with `mvn clean verify`. The build must pass with all tests green and SpotBugs reporting 0 bugs.

## Pull requests

* Keep changes focused and match the existing code style.
* Add or update tests for behavior you change.
* Add a line to `CHANGELOG.md` under the unreleased version.
* Document public API with JavaDoc.

## Bugs and ideas

Open an issue with the plugin version, server software and version, and steps to reproduce. Report security problems as described in [SECURITY.md](SECURITY.md).
